# 研究方向入门包

入门包使用同一个已保存研究方向，查询近 **365天 arXiv** 和近 **24个日历月会议论文**，合并来源版本、评审相关性，再生成带论文引用的方向导读与建议阅读顺序。论文仍使用本站原有阅读页，不另开一套阅读器。

## 开始之前

- 在自己的 Fork 同步包含此功能的代码，并配置好现有 GitHub 授权、DeepSeek 和检索所需配置。
- 在 GitHub Pages 站点操作；此入口通过 GitHub Actions 执行，不使用本地工作流替代。Embedding 等模型依赖走云端，云端不可用时任务会报错，不自动下载本地模型。
- 当前自动发布仅支持已存在的 **分支型 Pages（legacy）**：发布源为仓库**默认分支、根目录 `/`**。工作流不会自动创建站点或修改 Pages 配置；使用自定义 Actions 部署或 `/docs` 发布源时，需要另行对齐部署链路。

## 从前端启动

1. 打开设置中的会议管理，保存研究方向词条及其关键词、语义查询，确保词条已启用。
2. **恰好勾选一个词条**。有未保存修改或选择数量不为一个时，启动按钮不可用。
3. 选择会议范围。入门包只取所勾选组合里的**会议名称集合**，不取手选年份。例如勾选 `ICML 2026`，仍会查询 ICML 在滚动24个月范围内的可用年份；不勾选会议则使用全库支持会议，并在结果中说明缺失库存。
4. 在入门包区域设置以下参数，点击 **生成/续跑入门包**，阅读费用确认后启动。

| 参数 | 含义 |
| --- | --- |
| UTC 截止日期（不含当天） | 固定检索窗口的排他结束日；续跑必须保持不变 |
| 新增评审上限 | 每次 `0–5000` 篇，默认 `1000`；不是价格或 Token 上限 |
| 内容生成上限 | 精选阅读内容 `1–20` 篇，默认 `12`；实际合格论文不足时不凑数 |

例如截止日为 `2026-09-11`，arXiv 窗口为 `[2025-09-11, 2026-09-11)`，会议窗口为 `[2024-09-11, 2026-09-11)`。两者均不包含截止日当天，会议按日历月回推，不将“两年”简单替换成两个勾选年份。

> **新增评审上限为0不等于免费。** 它只表示本轮不新增论文相关性评审；缺失的中文总结、精读内容和入门导读仍可能调用模型。模型与云端服务按实际用量计费。

## 查看进度与续跑

GitHub Actions 中的任务名是 `Research direction starter pack`。如果评审预算不足，可能只生成“待续跑”的进度页；任务显示成功不代表完整导读已经生成，应同时检查入门包状态。

继续时保持**同一词条及其查询配置、同一会议范围、同一 UTC 截止日期**，再次点击生成/续跑。已完成的召回与评审检查点、阅读内容及导读缓存会尽量复用；可以调整单次评审上限。不要为了续跑把截止日改成新的一天，否则会形成不同窗口任务。

失败时先查看失败步骤，修正配置或等待外部服务恢复，再用相同参数续跑。缓存可能被 GitHub 淘汰，不保证永久保留或永远零新增调用。Actions 的 `starter-pack-results` 产物提供结果与进度排查材料，保留期为7天。

## 在哪里阅读

发布成功后，刷新 Sidebar，在 **专题回溯** 中进入入门包导读或进度入口。

- 导读提供方向概览、子方向和建议阅读顺序；每段说明附对应论文依据。
- “查看全部结果”按公布时间降序，另列时间边界待核实、仅元数据等记录。**阅读顺序与时间排序不是一回事。**
- 精选论文复用原阅读页、全文问答、中文总结与原有阅读状态；已有合适页面会优先复用。全文不可用的候选会明确列出，不冒充完成精读。
- 完整结果提供 **Gzip JSON 下载**，保留本次合并评审结果及来源版本；另有“去重待核对项”下载，便于人工检查不确定匹配。

这里的“完整结果”指**本次召回集合**，并非整个领域的所有论文，也不表示每条候选都生成了阅读页。

## 日期、精选与覆盖边界

arXiv 使用首次提交日期，不因版本更新而置顶。会议使用有依据的公布日期，并保留日、月、年或未知精度；投稿日期、抓取时间和年份占位不冒充精确公布日。

日期范围无法确认的版本、录用状态未经证实或只有标题的记录，不据此进入精选。只有在窗口内有合格来源证据、摘要可用且达到核心/补充分层条件的论文才参与精选；同一论文另有符合条件的 arXiv 版本时，会保留该来源依据。最终导读还要求阅读内容准备完成。

检索存在以下限制：

- arXiv 关键词按配置查询并分片；向量补漏是**每查询、每30天 Top100**。
- 会议是**每查询、每届、每路 Top50**，还受实际库存与 RPC 可用性限制。
- DOI、arXiv ID 和标题等用于版本合并，不确定的重复项保留供核对。
- 模型评分和导读不是人工金标准；导读依据输入标题、摘要和已有速览，近期窗口也不是完整领域史。

因此应先用明确的研究问题和排除条件配置专题，并抽查核心、补充和待复核结果；不能将入门包当作“找全所有相关论文”的证明。
