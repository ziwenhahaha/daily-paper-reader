## 摘要
视觉-语言-动作（VLA）模型的最新进展推动了机器人操作的进步，但观测到动作的学习仍受到一个根本性的转移可实现性差距的限制，该差距体现在三个紧密耦合的问题上：（i）转移歧义性。当前视觉相似的观测可能对应不同的操作阶段，并暗示不同的后续转移。（ii）预测与执行的失配。视觉上合理的未来观测预测并不一定对应物理上可实现的转移。（iii）经验与实现的失配。历史上可执行的动作模式在当前场景中不一定能实现预期的转移，因此需要根据上下文进行自适应调整。为此，我们提出了UniMPA，一种统一的记忆-预测-动作模型，通过共享的以动作为锚点的转移接口来解决上述问题。（i）UniMPA引入持续-选择性未来预测机制，通过建模预期的未来状态演化来解决转移歧义性。持续性潜在流持续追踪任务级别的进展，而转移关键像素流则通过基于记忆的预测选择性地解析细粒度的交互变化。（ii）为了评估预期转移的物理可执行性，预测的转移查询时序视觉-动作记忆库。该记忆库检索历史上已实现的视觉-动作经验，将未来预测锚定在可执行的证据上。（iii）为了使可执行的经验适应当前场景，动作-视觉记忆库从历史动作演化中检索以视觉为锚点的动作原型。随后，原型偏置流将流的源头向历史支持的动作流形偏移，以实现上下文自适应的精炼。

## Abstract
Recent advances in Vision-Language-Action (VLA) models have improved robotic manipulation, yet observation-to-action learning remains limited by a fundamental transition realizability gap, manifested in three tightly coupled problems: (i) Transition ambiguity. Visually similar current observations may correspond to different manipulation phases and imply different subsequent transitions. (ii) Prediction--execution mismatch. A visually plausible predicted future observation does not necessarily correspond to a physically realizable transition. (iii) Experience--realization mismatch. A historically executable action pattern may not necessarily realize the intended transition in the current scene and therefore requires context-aware adaptation. Accordingly, we propose UniMPA, a Unified Memory-Prediction-Action model that addresses these problems through a shared action-grounded transition interface. (i) UniMPA introduces Persistent-Selective Future Prediction to resolve transition ambiguity by modeling the intended future state evolution. A persistent latent stream continuously tracks task-level progress, while a transition-critical pixel stream selectively resolves fine-grained interaction changes through memory-grounded prediction. (ii) To assess the physical executability of the anticipated transition, the predicted transition queries a temporal Visual-Action Memory Bank. The bank retrieves historically realized visual-action experience, grounding future prediction in executable evidence. (iii) To adapt executable experience to the current scene, an Action-Visual Memory Bank retrieves visually grounded action prototypes from historical action evolution. Prototype-Biased Flow then shifts the flow source toward a historically supported action manifold for context-aware refinement.

# UniMPA 论文总结

## 1. 论文核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型近年来显著推动了机器人操作的发展，但现有方法核心瓶颈并非简单的"观测→动作"映射，而是如何推断任务相关的视觉转移并以可执行的动作实现该变化。
- **关键概念：转移可实现性差距（Transition Realizability Gap）**：作者将这一高层问题分解为三个紧密耦合的具体表现：
  - **转移歧义性（Transition Ambiguity）**：视觉相似的当前观测可能对应不同的操作阶段，并暗示不同的后续转移（例如 T 恤折叠中相似的布局可能处于折叠启动、继续、夹爪调整或释放阶段）。
  - **预测-执行失配（Prediction–Execution Mismatch）**：视觉上合理的未来预测不一定对应物理可实现的过渡。
  - **经验-实现失配（Experience–Realization Mismatch）**：历史可执行的动作模式在新场景中可能因位姿、接触条件变化而失效，需要上下文自适应。
- **整体含义**：作者将三者视为同一缺失接口的不同表现——即缺少一个连接"意图状态演化"与"可执行动作生成"的统一桥梁。论文提出 UniMPA（Unified Memory-Prediction-Action），通过共享的"以动作为锚点的转移接口"将预测、记忆与动作融合为 anticipate–ground–refine 的统一过程。

## 2. 方法论

### 2.1 整体框架与形式化
- 将"转移"定义为条件状态演化算子 $T_t^\Delta(\cdot|X_t)$，而非简单的像素差 $V_{t+\Delta}-V_t$。当前上下文 $X_t=\{V_t,\ell,q_t,H_t\}$ 输入模型，未来观测 $V_{t+\Delta}$ 仅作为训练监督目标。
- 三系统架构：VLM 主干（π0.5 / PaliGemma-2B + Gemma 311M 动作专家）+ 新增的 **World Expert**。三个流通过分层跨专家注意力机制交互（块级可见性 mask，使世界专家读取视觉-语言前缀，动作专家同时访问视觉-语言与世界转移表示）。
- 三组件设计对应三问题：
  1. **Persistent-Selective Future Prediction** 解决转移歧义性。
  2. **Visual-Action Memory Bank（V-A Bank）** 解决预测-执行失配。
  3. **Action-Visual Memory Bank + Prototype-Biased Flow** 解决经验-实现失配。

### 2.2 Persistent-Selective Future Prediction（持续-选择性未来预测）
- **持续性潜在预测**：World Expert 输出 16 个零初始化的可学习转移 token $Q_0$，经 Transformer 处理后得到 $Z_t^{tr}$。训练时通过轻量预测头将 $Z_t^{tr}$ 投影到 V-JEPA 2 潜在空间，与冻结的未来 V-JEPA 2 特征对齐，作为持续监督。
  $$L_{lat} = \sum_{\nu\in U}\frac{1}{N^\nu d_f}\|\hat{F}_{t+\Delta}^\nu - \text{sg}(f_{JEPA}(I_{t+\Delta}^\nu))\|_2^2$$
- **Transition-Critical Trigger Gate（转移关键触发门）**：仅在关键过渡时刻激活像素解码。结合三类信号：
  - 语义变化分数 $r_t^{lat}$（主视角预测潜在与当前潜在的距离）。
  - 动作指标：平移幅度 $b_t^p$、旋转幅度 $b_t^r$、夹爪状态切换 $b_t^g$（或双臂关节空间变体）。
  - 任一信号超过阈值则 $m_t=1$，触发像素级监督 $L_{pix}=m_t\sum_\nu \frac{1}{|\Omega^\nu|}\|\hat{I}_{t+\Delta}^\nu - I_{t+\Delta}^\nu\|_1$。
- **关键点**：未来像素预测仅用于在关键时刻校准 $Z_t^{tr}$，而 Action Expert 直接消费 $Z_t^{tr}$ 而非解码后的未来图像。

### 2.3 Transition-Aligned Bidirectional Memory（转移对齐的双向记忆）
- 双向存储条目 $M_{e,t}=\{(k_{v,e,t}^\nu, u_{v,e,t}^\nu)_{\nu\in U}, (k_{a,e,t}, u_{a,e,t}), e, t\}$。
- **键构造**：视觉键由冻结 V-JEPA 2 编码 + 投影 + 均值池化 + $\ell_2$ 归一化得到；动作键由近期动作历史 $H_t$ 投影得到。
- **值构造（时序建模）**：使用 **stateful Mamba** 维护每个视图的视觉时序状态 $h_{v,t}^\nu$ 与动作时序状态 $h_{a,t}$。
- **跨流过渡锚定**：
  - 视觉记忆通过动作时序状态与语义 token 的注意力获得动作条件化的视觉表示 $R_{v,t}^\nu$。
  - 动作记忆通过多视角视觉时序表示与历史动作的注意力获得视觉锚定的动作表示 $R_{a,t}$。
- **训练目标（Stage 1）**：
  - $L_{rec}$：未来图像 + 未来动作块的重建。
  - $L_{ret}$：检索仿真——根据余弦相似度的软检索分布解码未来，评估"检索到的值是否预测正确未来"。
  - $L_{pair}$：跨模态配对损失（InfoNCE 双向版本）将同一物理转移对应的视觉与动作表示对齐。
  - 总目标 $L_{bank}=L_{rec}+\lambda_{ret}L_{ret}+\lambda_{pair}L_{pair}$。
- **粗到细时序检索**：
  - 粗选：选出最相关 episode $e^*=\arg\max_e \max_s \text{sim}(q_t, k_{e,s})$。
  - 细选：在 $e^*$ 内做软加权聚合，避免跨不同任务阶段或执行策略的记忆混合。

### 2.4 Action-Manifold Prototype Refinement（动作流形原型精炼）
- **Action Proposer**：将检索到的动作值 $\bar{u}_{a,t}$ 与近期动作历史 $H_t$ 融合，得到动作流形先验 $P_{a,t}=h_{prior}([\phi_{prev}(H_t),\bar{u}_{a,t}])$。
- **Prototype-Biased Flow**：把零均值高斯流源平移到历史支持的运动区域：
  $$\tilde{\epsilon}_t=\epsilon_t+\lambda_p P_{a,t},\quad p(\tilde{\epsilon}_t|P_{a,t})=\mathcal{N}(\lambda_p P_{a,t}, I)$$
- Action Expert 接收视觉-语言上下文 $C_t$、未来监督的转移表征 $Z_t^{tr}$ 与原型条件化的动作上下文，通过流匹配预测速度场 $\hat{u}_\rho=W_o Z_t^a$，采用标准 flow-matching 损失 $L_{act}$。
- 总体 Stage-2 目标：$L_{UniMPA}=L_{act}+\lambda_{lat}L_{lat}+\lambda_{pix}L_{pix}$。
- **推理路径**：保留 World Expert 与 Action-Visual Memory Bank；去除 latent/pixel 解码头。缓存 VLM 与 World Expert 的层间 K/V 供动作专家在 10 步 Euler 流匹配迭代中复用。

## 3. 实验设计

### 3.1 仿真基准（4 个）
- **LIBERO**：Spatial / Object / Goal / Long 四套任务，2000 次 rollout 总评估。
- **LIBERO-Plus**：七种扰动维度（Camera / Robot / Language / Light / Background / Noise / Layout）下的零样本鲁棒性测试，共 10,030 次 rollout。
- **RoboTwin 2.0**：11 类代表性任务的 Clean→Randomized（Hard）零样本泛化评估，每任务 100 rollout（扩展评估达 44 任务）。
- **VLABench**：语言条件操作，6 类任务（Select Painting / Book / Drink / Chemistry Tube / Add Condiment / Insert Flower）。

### 3.2 真实世界任务（2 个平台 × 7 类任务套件）
- **平台**：AgileX Cobot Magic（基于 Mobile ALOHA）与 GALAXEA R1 Lite（23-DoF 移动双臂）。
- **任务套件（7 类）**：
  - A. 语义重排与分类
  - B. 关节体与容器交互
  - C. 精密装配与几何操作
  - D. 可变形与工具介导操作
  - E. 双臂协调
  - F. 动态与反应式操作
  - G. 长视野组合与恢复
- **评估规模**：GALAXEA 共 21 任务（每套件 3 个），AgileX 共 7 个代表任务。每任务 25 次独立试验，并采用渐进式 checkpoint 评估 Task Success Rate（TSR）与 Cumulative Success Rate（CSR）。

### 3.3 对比方法
- **通用 VLA**：OpenVLA、OpenVLA-OFT、UniVLA、π0、π0-Fast、π0.5、VLA-Adapter、HoloBrain、GuidedVLA、X-VLA 等。
- **基于预测的 VLA/WAM**：WorldVLA、DreamVLA、VLA-JEPA、FutureVLA、LaMP、Cosmos Policy、Fast-WAM 等。
- **基于记忆的 VLA**：MemoryVLA、MemoryVLA++、VF-VLA、Libra-VLA 等。
- **RoboTwin 2.0**：ACT、DP、DP3、π0、π0.5、RDT、UP-VLA、KAM-WM、TwinVLA、BagelVLA、HALO 等。

## 4. 资源与算力
- **GPU**：4–16 张 NVIDIA Pro6000 GPU（按基准规模分级；LIBERO 用 4 张，RoboTwin 2.0 / VLABench 用 8 张，真实世界用 16 张）。
- **训练阶段**：
  - Stage 1（记忆预训练）：10 epochs，AdamW，lr=1e-4，truncated BPTT 8 步。
  - Stage 2（策略微调）：20k–30k 步，AdamW，$\beta_1=0.9,\beta_2=0.95$，峰值 lr=5e-5（VLABench 为 5e-6），warm-up 5k–10k 步；bfloat16 混合精度。
- **训练预算**：仅使用 π0.5 baseline 的 25%–50% epochs（LIBERO 用 25%，RoboTwin 2.0 / VLABench 用 50%）。
- **World Expert 配置**：18 层，hidden 1024，8 头，FFN 4096；16 个可学习转移查询；记忆维度 512；2 层 Mamba 状态编码（state dim 16）；流匹配推理用 10 步 Euler。
- **论文未详细披露**：训练总时长（小时/天数）、显存占用、数据集制作与标注成本等。

## 5. 实验数量与充分性

### 7 优点（续）

- **双向记忆 + 粗到细检索**：V-A 与 A-V 两个 bank 分别从转移查询与动作查询两端检索可执行经验，并通过 episode 约束与软加权聚合，有效避免跨任务阶段或执行策略的记忆混合问题。
- **持续-选择性预测机制**：通过潜在预测持续监督 + 像素预测仅在关键转移时刻触发的设计，在训练效率与监督粒度间取得良好平衡，避免了密集像素重建带来的噪声与冗余。
- **动作流形原型精炼**：Prototype-Biased Flow 通过将零均值高斯流源平移到历史支持的运动区域，使动作生成既保留先验知识又能根据当前上下文自适应，相比直接复制历史动作（NN Copy）有大幅提升。
- **高效训练**：仅使用 π0.5 baseline 的 25%–50% epochs 即可达到更优性能，展示了未来预测与记忆检索作为归纳偏置的有效性。
- **全面实验验证**：覆盖 4 个仿真基准 + 2 个真实世界平台（共 28 个真实任务），包含 6 类细致消融研究，并通过渐进式 checkpoint 评估提供了细粒度的失败模式分析。
- **良好的工程实现**：推理阶段缓存 VLM 与 World Expert 的层间 K/V，10 步 Euler 流匹配复用缓存，在保证效果同时兼顾效率。

## 8. 局限性

- **作者明确承认的局限（附录 G）**：
  - **异步记忆构建**：记忆条目仅在当前 rollout 完成后才可被未来 rollout 使用，存在一个 rollout 的延迟，理论上限制了对全新任务结构的即时适应能力。
  - **固定时间预测尺度**：未来预测的 $\Delta$ 为固定值，未建模不同任务可能需要不同预测 horizon 的情况。
  - **二元触发门**：Trigger Gate 当前为二元（开/关）决策，未对转移关键程度做连续量化，可能在过渡性阶段丢失部分有用信号。
  - **单原型动作流形引导**：当前设计每个时间步只使用单个动作原型先验，未建模多模态动作分布或多原型集成。
- **记忆检索依赖历史演示**：双向记忆的有效性建立在训练数据覆盖足够多样化的状态-动作对上，对于训练数据中罕见的状态或物体组合，检索质量可能下降。
- **真实世界实验规模有限**：每个真实任务 25 次试验虽达到主流标准，但对于统计显著性与任务覆盖广度而言仍属中等规模，且任务套件集中在 7 类典型场景。
- **World Expert 训练成本**：额外的 18 层 Transformer + Mamba 状态编码器带来一定计算开销，且分两阶段训练增加了工程复杂度。
- **未充分披露的细节**：论文未详细报告训练总时长（小时/天数）、各基准的显存峰值、数据集规模与标注成本等，限制了对计算开销与数据效率的完整评估。
- **跨平台泛化未完全验证**：尽管在 AgileX Cobot Magic 与 GALAXEA R1 Lite 两个平台上进行了评估，但未涉及其他类型机械臂（如 Franka、UR）或移动底盘异构平台。
- **语言条件推理深度有限**：VLABench 评估覆盖 6 类语言条件任务，但对复杂组合语言指令（如多步条件、否定、空间关系推理）的评估仍不充分。
