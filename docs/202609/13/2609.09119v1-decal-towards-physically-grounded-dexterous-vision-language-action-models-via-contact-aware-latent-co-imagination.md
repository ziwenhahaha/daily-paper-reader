灵巧操作涉及与物理世界之间接触密集且细粒度的交互，由于严重的视觉遮挡和复杂的接触动力学，给现有的视觉-语言-动作（VLA）模型带来了重大挑战。尽管近期一些工作已将触觉感知引入机器人操作中，但大多数方法仍依赖于同质化的多模态融合，缺乏自适应的触觉集成以及对物理动力学的显式建模。在本工作中，我们提出了 DeCAL，一种基于物理约束的灵巧视觉-语言-动作模型，统一了接触密集型灵巧操作中的理解、想象与动作生成能力。DeCAL 基于混合 Transformer（MoT）架构构建，利用针对每种能力的专门专家模块，同时实现各模块间高效的信息流。为了有效利用触觉信息，我们引入了自适应视觉-触觉融合模块，通过接触感知门控策略动态调节触觉交互。此外，我们提出了视觉-触觉潜空间协同想象方法，对视觉和触觉动力学进行联合建模，使策略具备隐式的物理世界知识。实验结果表明，DeCAL 在所有任务上均持续取得最先进的性能，平均成功率达到 71%，进度成功率达到 83.4%，同时还展示了对未见场景的强大泛化能力。项目网站位于 https://aureleopku.github.io/DeCAL。

## Abstract
Dexterous manipulation involves contact-rich and fine-grained interactions with the physical world, posing significant challenges for existing vision-language-action (VLA) models due to severe visual occlusions and complex contact dynamics. While recent works have incorporated tactile sensing into robotic manipulation, most approaches still rely on homogeneous multimodal fusion, lacking adaptive tactile integration and explicit modeling of physical dynamics. In this work, we present DeCAL, a physically-grounded dexterous vision-language-action model that unifies understanding, imagination and action generation for contact-rich dexterous manipulation. Built upon a Mixture-of-Transformers (MoT) architecture, DeCAL leverages specialized experts for each capability while enabling efficient information flow among them. To effectively leverage tactile information, we introduce Adaptive Visuo-Tactile Fusion that dynamically regulates tactile interactions via a contact-aware gating strategy. Furthermore, we propose Visuo-Tactile Latent Co-Imagination to jointly model visual and tactile dynamics, equipping the policy with implicit physical world knowledge. Experimental results show that DeCAL consistently achieves state-of-the-art performance across all tasks, attaining a 71% average success rate and an 83.4% progress success rate, while also demonstrating strong generalization to unseen scenarios. The website is available at https://aureleopku.github.io/DeCAL.

# DeCAL 论文总结

## 1. 核心问题与研究动机

- **任务背景**：灵巧操作（dexterous manipulation）是人类日常生活中的基础能力，涉及大量接触密集（contact-rich）且细粒度的物理交互，例如插拔、擦拭、拧瓶盖等。
- **现有 VLA 模型的不足**：
  - 现有视觉-语言-动作（VLA）模型在多指灵巧手任务上虽取得进展，但仍受限于**严重视觉遮挡**（多指手自遮挡）与**复杂接触动力学**。
  - 现有方法对**视觉信息过度依赖**，缺乏对接触物理信息的显式建模。
- **触觉融合的局限**：
  - 既有触觉融合方法通常把触觉当作**辅助信号**与视觉做"同质化（homogeneous）"拼接，缺乏**自适应调制**。
  - 多数方法属于**反应式（reactive）**策略，无法显式预测未来接触状态，限制了对演化接触过渡的推理能力。
- **本文目标**：构建一个能统一**理解、想象与动作生成**的物理基础 VLA 框架，使灵巧手能够自适应地利用触觉并对未来视触觉动力学进行前瞻推理。

## 2. 方法论

### 2.1 整体架构：Mixture-of-Transformers (MoT)

- 三个专用 Transformer 专家通过**有向知识共享**（单向注意力掩码）协作：
  1. **Understanding Expert (VTLM)**：基于 Qwen3-VL，处理语言指令、多视角视觉与触觉特征，输出上下文嵌入。
  2. **Generation Expert (World Model)**：基于 Qwen3，建模视触觉动力学，预测未来视触觉潜变量。
  3. **Action Expert (FM Model)**：基于 Qwen3，通过**Factorized Flow Matching** 解耦手臂与手部动作生成。
- **跨专家联合注意力**：信息单向流动 理解 → 生成 → 动作；在理解与生成专家内部双向注意；动作专家采用不对称掩码（状态 token 可关注所有前置 token，动作 token 可关注自身、状态 token 与前置 token）。

### 2.2 自适应视触觉融合（Adaptive Visuo-Tactile Fusion）

- **触觉特征提取**：
  - 多指 deform map 经共享 ResNet 编码、空间池化与跨指 Transformer 融合。
  - 输出两类表征：**局部触觉 token**（细粒度接触细节）与**全局触觉 token**（整体接触状态）。
- **跨注意力注入**：以视觉-语言嵌入作为 query，局部触觉 token 作为 K/V，通过残差连接融合。
- **接触感知门控（Contact-Aware Gate）**：
  - 核心公式：$\tilde{X} = X + \sigma \odot \mathrm{CrossAttn}(Q_{vl}, K_{local}, V_{local})$，其中 $\sigma = \mathrm{Gate}(z_{global})$。
  - 设计动机：接触是**间歇性**事件，无接触时持续注入触觉会干扰视觉注意力；门控机制根据全局接触状态**自适应调节**触觉贡献。

### 2.3 视触觉潜在协同想象（Visuo-Tactile Latent Co-Imagination）

- **触觉潜变量预测**：
  - 用力编码器将各指尖 6-DoF 力信号映射为嵌入，生成触觉潜变量。
  - 潜变量可解码为多粒度表征：**原始触觉图像、deform map、6-DoF 力/力矩**。
- **视觉潜变量预测**：
  - 多视角图像经 **Cosmos VAE tokenizer** 编码，再用 8×8 卷积将 32×32 网格压缩为 4×4。
  - 通过复用 Understanding Expert 的 KV cache **并行解码**未来帧，避免自回归延迟。
- **训练监督**：
  - 视觉潜变量直接回归 Cosmos VAE 目标；
  - 触觉潜变量通过重建未来原始图、deform map、6-DoF 力**间接监督**；
  - 推理时仅输出潜变量，无需像素级重建。

### 2.4 分解式流匹配（Factorized Flow Matching）

- **动机**：手臂（6-DoF）与手部（22-DoF）动力学差异显著，共享去噪过程会掩盖细粒度灵巧行为。
- **做法**：手臂与手部动作**独立噪声初始化**，经 MLP 投影为独立 token 序列后联合处理，再分别解码。
- **训练目标**：$\mathcal{L}_{total} = \lambda_v \mathcal{L}_{visual} + \lambda_t \mathcal{L}_{tactile} + \mathcal{L}_{action}$。

## 3. 实验设计

### 3.1 任务与数据

## 6. 主要结论与发现

- **性能**：DeCAL 在 6 个任务全部 SOTA，平均 SR **71%**、平均 PSR **83.4%**，超过最强基线 ≥15% 绝对提升（Figure 1）。
- **最佳表现任务**：Wipe Vase（SR 100%/PSR 100%）、Twist Cap（SR 80%/PSR 93.3%）；最弱任务：Screw Light Bulb（SR 40%/PSR 48.8%）。
- **诊断结论**：
  - 视觉 VLA 早期抓取阶段尚可，但接触密集后期阶段显著退化；
  - 触觉专家策略在接触阶段更强，但缺乏对物理动力学的显式建模导致长程规划能力弱；
  - 简单注入触觉（InternVLA-A1t）会扰动视觉表征分布，反而降低视觉接地与抓取精度；
  - 自适应门控 + 视触觉协同想象**同时**增强了接触感知与视觉接地能力。
- **泛化**：4 个 OOD 场景中均显著优于基线，尤其在未知物体设置下 SR 达 75%，比最强基线高约 30 个百分点。

## 7. 优点

- **统一架构**：MoT 三专家 + 跨专家联合注意力 + 单向信息流，使理解、想象、动作生成在统一潜空间内协同。
- **自适应触觉融合**：接触感知门控以全局触觉 token 调节局部注入权重，形式简洁且有效解决了"无接触时触觉噪声扰动"的问题。
- **视触觉协同想象**：把视觉与触觉动力学放在同一潜空间联合预测，并复用 KV cache 实现并行解码，兼顾效率与表达力。
- **分解式流匹配**：针对高 DoF 灵巧手将手臂与手部动作生成解耦，缓解了共享去噪过程对手指细粒度控制的稀释。
- **公平基线对比**：构造 InternVLA-A1t 剥离"加触觉"贡献，使触觉带来的增益可归因。
- **诊断充分**：t-SNE、门控可视化、力预测曲线、分阶段 SR 等多个角度验证组件有效性。
- **强实机性能**：71% 平均 SR、0.27s 推理延迟，达实时部署门槛。

## 8. 不足与局限

- **触觉传感器依赖**：性能受传感器噪声、标定误差、模型漂移影响，长时高负载下可能退化。
- **遥操作限制**：操作员缺少指尖力反馈，导致示教中接触调整延迟，可能限制示教质量。
- **缺少大规模视触觉预训练**：作者明确指出未利用大规模视触觉预训练数据，预训练扩展是重要未来方向。
- **OOD 评估覆盖**：泛化实验仅在 Twist Cap 单任务上做 4 种 OOD，未覆盖其他任务；ID 分阶段对比中基线仅给出 3 个对照，统计显著性未做严格检验。
- **失败模式**：bimanual 协调（如 Pipetting 交接）易因手-臂时间错位失败；头相机视场有限，大范围运动时目标可能脱离视野。
- **触觉生成质量**：预测的 deform map 仅能保留高响应接触区域，细粒度结构仍有损失（附录 E.1），对下游决策可能产生误差传播。
- **公平性细节**：基线所用训练数据量、超参与硬件不完全对齐（如 ViTacFormer、DECO 使用 1–4×H100，而 DeCAL 使用 8×H100），可能对性能对比造成隐性偏差。
- **应用边界**：当前框架针对固定 56-DoF 双臂-双手平台，对其他灵巧手构型或单臂平台的迁移性未验证。
