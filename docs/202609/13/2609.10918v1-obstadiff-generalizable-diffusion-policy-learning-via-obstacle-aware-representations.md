## 摘要
模仿学习在机器人操作中取得了令人瞩目的成果，然而现有大多数方法假设背景干净，并且缺乏用于障碍物感知运动生成的显式机制。将此类策略推广到具有非结构化障碍物的杂乱真实场景仍然是一项关键泛化挑战。我们提出了 ObstaDiff，一种带有轻量级障碍物感知视觉编码器的分解式扩散策略框架。ObstaDiff 提取结构化的目标—障碍物—背景表示，使下游对齐策略能够生成朝向以目标为中心的瓶颈位姿的末端执行器轨迹，同时对周围障碍物进行推理。我们在温室中对每种方法进行了 61 次真实机器人试验（共 366 次执行）。ObstaDiff 取得了 75.41% 的平均任务成功率和 8.20% 的平均障碍物碰撞率，优于代表性的模仿学习基线方法，并提升了在杂乱农业场景中的泛化能力。

## Abstract
Imitation learning has achieved impressive results in robotic manipulation, yet most existing approaches assume clean backgrounds and lack explicit mechanisms for obstacle-aware motion generation. Extending such policies to cluttered, real-world scenes with unstructured obstacles remains a key generalization challenge. We present ObstaDiff, a decomposed diffusion-policy framework with a lightweight obstacle-aware visual encoder. ObstaDiff extracts a structured target-obstacle-background representation, enabling the downstream alignment policy to generate end-effector trajectories toward a target-centered bottleneck pose while reasoning about surrounding obstacles. We evaluate ObstaDiff on 61 real-robot greenhouse trials per method (366 executions in total). ObstaDiff achieves 75.41% average task success and 8.20% average obstacle collision rate, outperforming representative imitation-learning baselines and improving generalization in cluttered agricultural scenes.

# ObstaDiff 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现有模仿学习方法在机器人操作中假设背景"干净"，且缺少**显式的障碍物感知机制**，因此难以泛化到充满非结构化障碍物（叶片、茎秆、枝条、工具等）的杂乱真实场景。
- **场景聚焦**：以**农业温室场景**（如采摘、触碰辣椒果实）为典型代表，机器人需要在狭窄、不规则通道中接近小目标，同时应对光照变化、视角变化、目标外观变化等高视觉变异性。
- **关键症结**：标准的端到端视觉编码器将目标、障碍、背景信息纠缠在单一潜空间特征中，导致扩散策略生成轨迹时**忽略附近障碍物**，特别是在分布漂移下表现急剧下降。
- **本文主张**：通过引入**任务结构化的视觉表征**，使"目标—障碍物—背景"三者的语义角色显式化，让下游策略知道"应当接近什么、应当规避什么"，从而提升杂乱场景下的泛化能力与避障能力。

## 2. 方法论

### 2.1 整体框架（解耦式扩散策略）

- 任务分解为两阶段：
  - **对齐阶段（Alignment）**：基于扩散策略生成末端轨迹，将末端执行器从起始位姿运动到目标周围的"瓶颈位姿" $p^*$；
  - **交互阶段（Interaction）**：到达瓶颈位姿后切换为**轨迹回放（replay）**，执行近距离交互动作（如触碰果实）；
- 形式化分解为：
  $\pi(a_{0:T} | o_{0:T}) = \pi_{\text{align}}(a_{0:T_b} | o_{0:T_b}) \cdot \pi_{\text{inter}}(a_{T_b:T} | p^*)$；
- 切换点 $T_b$ **不预先指定**，由在线数据驱动规则决定（详见 2.4）。

### 2.2 目标—障碍物—背景（TOB）结构化观测

- 输入：眼在手 RGB-D 相机观测；
- 处理流程：
  1. 使用**微调后的 YOLOv8s-Worldv2**（开放词汇检测器）检测目标和障碍区域；
  2. 用 **MobileSAM** 将检测框细化为像素级掩码；
  3. 三类标签：背景（0）、障碍（1）、目标（2），生成三通道二值掩码 $m_{\text{bg}},\, m_{\text{obs}},\, m_{\text{tar}}$；
  4. 与对齐、归一化的深度图 $\bar{d}_t$ 拼接，得到 **4 通道 TOB 张量** $x_t = [m_{\text{bg}}; m_{\text{obs}}; m_{\text{tar}}; \bar{d}_t] \in [0,1]^{4 \times 240 \times 320}$；
- 关键思想：**显式编码语义角色**，抑制背景外观变异，凸显目标—障碍物空间关系。

### 2.3 障碍感知结构化编码器（StructuredObsEncoder）

- 输入并非自然图像，**不能直接用 ResNet18 等通用骨干**，因此设计轻量双分支编码器：
  - **语义分支**：处理三通道掩码 → Conv-GN-ReLU ×4 → SpatialSoftmax → 32 个关键点坐标 → $z_{\text{seg}} \in \mathbb{R}^{64}$；
  - **深度分支**：处理单通道深度图 → 同样结构 → 16 个关键点坐标 → $z_{\text{dep}} \in \mathbb{R}^{32}$；
- 融合末端 7 自由度位姿 $e_t$，得到 **103 维条件向量**：
  $c_t = [z_{\text{seg}}; z_{\text{dep}}; e_t] \in \mathbb{R}^{103}$；
- 两个观测步叠加后形成 **206 维** U-Net 条件输入。
- 关键点空间 softmax 输出"关键点式坐标"，而非密集特征，有利于捕获**目标—障碍物的相对空间布局**。

### 2.4 对齐阶段扩散策略

- 标准 DDPM 风格条件扩散，预测一段末端动作序列 $A_0 = \{a_1, \ldots, a_{T_a}\}$；
- 前向扩散：$q(A_k|A_0) = \mathcal{N}(A_k; \sqrt{\bar\alpha_k}A_0, (1-\bar\alpha_k)I)$；
- 训练损失：$\epsilon$-预测 MSE，$L = \mathbb{E}_{k,A_0,\epsilon}[\|\epsilon - \epsilon_\theta(A_k, c_{1:n}, k)\|^2]$；
- 推理：DDIM 采样 100 步；执行预测序列的前 8 步（预测 horizon 16，receding horizon 方式）。

### 2.5 数据驱动瓶颈切换

- **回放库** $\mathcal{D}_{\text{replay}} = \{(g_0^i, A_{\text{inter}}^i)\}_{i=1}^{N_{\text{lib}}}$ 包含 26 条从瓶颈位姿出发的交互轨迹；
- 目标状态由"目标框中心 + 中心区域深度（第 20 百分位）"组成；
- **门控最近邻规则**：仅当某回放条目的深度已 ready 且图像平面误差 $e_u + e_v$ 最小时才被选中；当 $e_{i^*,u} + e_{i^*,v} \le \epsilon_{uv}$（$\epsilon_{uv}=0.2$）时切换到回放执行；
- 优势：避免在近距离依赖不可靠的眼在手深度，且便于更换交互目标（仅替换回放库即可，无需重训对齐策略）。

## 3. 实验设计

### 3.1 硬件与场景

- **平台**：7 自由度 Sawyer 机械臂 + 眼在手的 Intel RealSense D455 RGB-D 相机；
- **场景**：室内温室测试台，模拟真实温室中目标（紫色 / 绿色辣椒果实）周围环绕障碍植物（茎、叶）的空间约束。

### 3.2 数据与演示

- 演示收集：使用 Sawyer 重力补偿示教模式，采集 **90 条专家对齐演示**（紫色辣椒），3 种障碍配置各 30 条；
- 回放库：**26 条**交互轨迹（瓶颈位姿 → 触碰目标）；
- 训练/验证划分：随机种子 42，10% 留出验证。

### 3.3 评估基准（三种泛化设置）

- **TPG（Target-Pose Generalization）**：10 个目标位置 × 2 种姿态 = **20 次试验**；
- **OLG（Obstacle-Layout Generalization）**：3 种障碍排列 × 7 个障碍位置 = **21 次试验**；
- **TAG（Target-Appearance Generalization）**：训练时未见过的两种绿色辣椒各 10 个位姿 = **20 次试验**；
- 总计 **61 次试验 / 方法 × 6 方法 = 366 次真实机器人执行**。

### 3.4 对比方法

- **ACT (RGB)**：标准 RGB 输入的动作分块 Transformer 基线；
- **ACT (TOB)**：ACT 改用 TOB 输入，用于检验 TOB 对非扩散方法的迁移性；
- **DP (RGB)**：标准 Diffusion Policy（ResNet-18 + RGB）；
- **DP (RGB-D)**：DP 增加对齐深度通道（仅追加深度，验证深度的单独贡献）；
- **DP (TOB)**：DP 接收与 ObstaDiff 相同的 4 通道 TOB 输入（信息匹配控制，剥离结构化编码器的影响）；
- **ObstaDiff**：完整方法（TOB + 结构化编码器 + 扩散对齐）；
- **未对比 DP3**：因眼在手 D455 + 密集枝叶导致重建点云不稳定，作者明确说明并放弃 DP3 对比。

### 3.5 评价指标

- **TSR**：任务成功率（主要指标）；
- **OCR**：障碍物碰撞率；
- **TCT**：任务完成时间（仅在成功 TPG 试验上统计）；
- **Traj. Smooth**：轨迹平滑度（末端位姿/动作的时间变化）。

## 4. 资源与算力

- **部署**：NVIDIA RTX 2080 Ti 工作站；
- **训练**：NVIDIA RTX 6000 Ada 工作站；
- **训练超参**：所有扩散变体共享 AdamW（lr=1e-4、wd=1e-6、betas=(0.95, 0.999)）、**250 轮**、EMA 评估、DDIM 调度器（平方余弦噪声）、100 扩散步；ACT 训练 2000 轮；
- **批大小差异**：DP(TOB) 与 ObstaDiff 用 batch=32；DP(RGB) 与 DP(RGB-D) 用 batch=16（作者指出 DP(TOB) 与 ObstaDiff 共享 batch size，不混淆视觉编码器的对比）；
- **未明确给出**：单次训练 wall-clock 时长、数据集总大小、GPU 显存占用等。

## 5. 实验数量与充分性

- **实机器人执行规模**：每个方法 61 次独立配置试验，共 366 次真实执行，**工程量较大**；
- **基线覆盖**：
  - 包含两套主流模仿学习骨干（ACT、DP）的多种输入变体（RGB、RGB-D、TOB），并设计 **信息匹配控制**（DP-TOB 与 ObstaDiff 仅编码器不同）以隔离各组件贡献；
  - 消融维度清晰：TOB 表示 vs. 结构化编码器 vs. 深度附加；
- **泛化维度**：覆盖目标位姿（TPG）、障碍物布局（OLG）、目标外观（TAG）三个轴，且每种试验都是**不同配置**而非同配置重复，衡量配置级泛化；
- **训练曲线对比**（图 4）：补充了 TOB 对训练稳定性的影响；
- **可能的局限**：未做**仿真大规模统计对比**，单一种植场景、单一种植作物，缺乏跨场景 / 多机器人平台的复现验证；DP3 由于工程原因未对比，可能影响公平性。

## 6. 主要结论与发现

- **成功率**：ObstaDiff 在 TPG 75.00%、OLG 71.43%、TAG 80.00%，**平均 TSR 75.41%**，全部超越所有基线；
- **碰撞率**：平均 OCR 仅 **8.20%**，相比 DP (RGB) 的 26.23% 和 ACT (RGB) 的 14.75% 显著降低；
- **信息匹配控制实验**：
  - 仅附加深度（DP→DP RGB-D）：TSR 从 49.18% → 50.82%（仅 +1/61），OCR 不变 → 深度本身贡献有限；
  - 仅替换为 TOB（DP→DP TOB）：TSR 反而下降到 45.90%，OCR 上升至 27.87%；OLG 上最差（成功率与碰撞率均为 38.10%/8/21）→ **TOB 表示必须与结构化编码器匹配才有效**；
  - ObstaDiff 完整方法比 DP(TOB) 高出约 **29.5 个 TSR 百分点**，归因于结构化编码器；
- **ACT 同样规律**：加入 TOB 后 OCR 从 14.75% → 11.48%、平滑度从 1.16 → 0.77 改善，但 TSR 从 45.90% 下降到 40.98% → 说明 **TOB 表示对不同策略类的迁移效果不一**；
- **训练稳定性**：TOB 输入能降低验证损失波动，但**更低的监督损失并不自动转化为更高的任务成功率**；
- **定性结论**：基线策略常直奔目标，易与近处植物发生接触；ObstaDiff 倾向于先对齐目标周围的自由空间，再进入瓶颈区域，体现真正的"障碍感知接近"行为。

## 7. 优点（亮点）

- **任务结构化表示**：TOB 把"该接近什么、该避开什么、该忽略什么"显式化，相比通用图像骨干更契合杂乱场景；
- **专用轻量编码器**：语义分支 + 深度分支 + 空间 softmax，将结构化输入压缩为紧凑的关键点坐标，强调目标—障碍物相对布局；
- **解耦式策略**：对齐与交互分离，只需更换回放库即可适配不同交互目标（采摘、触碰、检查等），便于工程部署；
- **数据驱动瓶颈切换**：避免硬编码位姿阈值，在近距离眼在手深度不可靠时切到回放，提升鲁棒性；
- **真实机器人验证规模大**：366 次真实执行覆盖三种泛化轴，并提供信息匹配消融控制，实验设计较为严谨；
- **对失败案例诚实披露**：明确说明未对比 DP3 的工程原因，体现科学严谨性。

## 8. 不足与局限

- **依赖外部检测器**：TOB 表征依赖 YOLOv8s-Worldv2 + MobileSAM，需要在约 80 张温室图像上做微调，对未见过类别或显著域漂移场景的迁移性未知；
- **目标仍需人工或 prompt 指定**：未解决**自主目标选择**与高层任务规划问题；
- **仅对齐阶段学习，交互阶段为回放**：避障效果只覆盖"接近阶段"，近距离接触操作仍受演示分布约束，泛化能力受限；
- **场景单一**：仅在一种室内温室台架、3 种障碍植物、1 种目标作物上测试，未涉及户外、跨作物、跨光照等更广泛农业环境；
- **DP3 未对比**：因移动眼在手设置下点云不稳定而放弃，可能让读者对"3D 几何方法 vs. TOB 表示"比较存疑；
- **批大小不一致**：DP(RGB)/DP(RGB-D) 与 DP(TOB)/ObstaDiff 批大小不同（16 vs. 32），虽作者声称关键对比已控制变量，仍可能引入隐性偏差；
- **算力信息不全**：未给出训练时长、显存占用、推理延迟等关键部署指标；
