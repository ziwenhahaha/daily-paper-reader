## 摘要
视觉-语言-动作（VLA）策略通常通过额外的梯度更新来适配新的操作设置，这在任务特定数据或算力稀缺时限制了快速部署。本文提出了 ICI-VLA，一个训练与检索框架，通过上下文演示使文本-动作视觉语言模型具备少样本测试时自适应能力。与主流基于动作特定多模态融合的 VLA 设计不同，ICI-VLA 保留了原生的文本生成接口。ICI-VLA 仅在离线训练阶段更新参数；在推理时，策略保持固定，并以检索到的微演示为条件生成动作。该框架将长轨迹分解为短小的、带语义标签的样例，并利用动态时间规整（DTW）挖掘正样本来训练 RD-Encoder，使检索到的上下文与当前子任务的阶段和几何信息对齐。我们进一步提出了目标动作掩码（Target Action Masking），这是一种上下文破坏目标，旨在减少直接复制动作的现象，并增强对当前观测的依赖。ICI-VLA 在 LIBERO 上达到了 97.7% 的平均成功率，在 RoboTwin 2.0 上达到了 60.4%，在 RoboTwin 2.0 上超过最高报告基线平均水平 19.3 个百分点，并在四项真实任务中取得了 83.2% 的成功率。这些结果表明，一个固定的 VLA 策略可以通过在测试时以时空对齐的演示为条件而受益。

## Abstract
Vision-Language-Action (VLA) policies are commonly adapted to new manipulation settings through additional gradient updates, which limits rapid deployment when task-specific data or compute is scarce. We present ICI-VLA, a training and retrieval framework that equips a text-action VLM with few-shot test-time adaptation through in-context demonstrations. Unlike mainstream VLA designs based on action-specific multimodal fusion, ICI-VLA retains the native text-generation interface. ICI-VLA updates its parameters only during offline training; at inference, the policy remains fixed and conditions action generation on retrieved micro-demonstrations. The framework decomposes long trajectories into short, semantically labeled examples and trains an RD-Encoder with positives mined by Dynamic Time Warping (DTW), aligning the retrieved context with the phase and geometry of the current subtask. We further introduce Target Action Masking, a context-corruption objective designed to reduce direct action copying and increase reliance on the current observation. ICI-VLA reaches average success rates of 97.7% on LIBERO and 60.4% on RoboTwin 2.0, exceeding the highest reported baseline average on RoboTwin 2.0 by 19.3 percentage points. It also achieves 83.2% across four physical tasks. These results indicate that a fixed VLA policy can benefit from conditioning on spatiotemporally aligned demonstrations at test time.

# ICI-VLA 论文总结

## 1. 核心问题与整体含义

- **核心问题**：现有 Vision-Language-Action（VLA）策略在面对新任务时需要额外采集任务特定数据并进行梯度微调，这在数据或算力稀缺时严重限制了快速部署。
- **背景动机**：
  - 主流 VLA（π0、OpenVLA-OFT、π0.5-KI 等）均依赖动作专用头（扩散头、离散动作 token 或自定义架构），属于"修改式"设计，工程复杂且可能损害 VLM 原生能力。
  - In-Context Learning（ICL）在 NLP 领域已成熟，但机器人 ICL 尚未稳健通用：长轨迹与短动作块之间存在**时间混叠（temporal aliasing）**，视觉/语义相似但需要不同动作的演示存在**语义-动态失配（semantic-dynamic mismatch）**，从而导致模型退化为"动作前缀复制"。
  - VLA-0 验证了"零修改"的纯 VLM 直接以文本形式生成动作仍可获得较强操作能力，为机器人 ICL 提供天然基础。

## 2. 方法论

### 核心思想
将"任务级参数更新"替换为"测试时检索-条件化"：策略参数在推理时完全冻结，仅通过检索到的时空对齐微演示来条件化动作生成。

### 三个阶段
- **Stage I：机器人演示库构建**
  - 基于 LIBERO、RoboTwin 2.0 与真实双臂 Aloha 约 11,200 条长程轨迹（共 ~139,659 条子任务示例）。
  - 用 Qwen3-VL 将长轨迹 `τ_i` 启发式分割为带语义标签的子任务 `{S_i,1, ..., S_i,n}`，每段配细粒度指令 `T_i,k`。
  - 每条微演示形式为 `E = ⟨T_i, T_i,k, O_i, Z_i, A_i:i+k⟩`，其中 `A_i:i+k` 是按 VLA-0 方式文本化的 k 步动作块。
  - 测试时由一个"视觉规划器"根据执行进度从全局指令 `T` 中激活当前子任务指令 `T_sub`。

- **Stage II：时空检索对齐（RD-Encoder）**
  - RD-Encoder 基于 Qwen3-VL-Embedding-2B 微调。
  - **语义硬过滤**：先用余弦相似度剔除语义不兼容候选（如只保留"操作抽屉"相关样本）。
  - **DTW 几何排序**：在语义兼容候选池中，以 DTW 距离最小者作为正样本 `P⁺`，同语义但相位错位的样本作为难负样本 `N⁻`。
  - 损失函数为 InfoNCE：`L_CL = -log [exp(e_Aᵀ e_P⁺/τ) / (exp(e_Aᵀ e_P⁺/τ) + Σ exp(e_Aᵀ e_N_i⁻/τ))]`，τ=0.07。
  - 离线训练迭代"检索→DTW 三元组挖掘→对比优化"5 轮；推理时 RD-Encoder 仅基于可观测输入排序，不使用目标动作。
  - 关键设置：保留语义候选前 64 名，DTW 最优者为正样本，每个子任务采 15 个相位错位难负样本，停止条件为正样本变动 < 5% 或达到 5 轮。

- **Stage III：基于 Target Action Masking 的 VLA 微调**
  - VLA 策略采用 Qwen3-VL-4B，不加任何动作头，动作完全以文本数值表示。
  - 在 prompt 中组织：系统指令 + 检索到的 3 条参考演示 + 当前查询 `(T, T_sub, O_t, Z_t)`。
  - **Target Action Masking（上下文破坏目标）**：训练时随机将目标动作 token 中的位置子集 `M` 替换为 `[MASK]`，仅对未掩码位置 `U` 计算动作似然损失 `L_act`。
  - 推理时关闭 masking，策略以冻结参数自回归生成动作块；演示上下文在策略置信度 < 0.65 时刷新。

### 公式核心
- 检索：`E* = argmax_{E∈D} s_φ(I_q, E)`
- 动作生成：`A_t:t+k ~ π_θ(· | I_q, E*)`
- DTW：`DTW(Traj_a, Traj_e) = min_W Σ δ(p_a,u, p_e,v)`

## 3. 实验设计

### 数据集与基准
- **LIBERO**：Spatial / Object / Goal / Long 四个子集，用于对象与空间条件操作。
- **RoboTwin 2.0**：高保真长程双臂任务，需精细时空协调，含 Easy / Hard 两类。
- **真实场景**：双臂 Aloha 系统，覆盖 Single-arm Grasp、Dual-arm Grasp、Drawer Placement、Object Sorting 四个任务，约 1,000 条遥操作轨迹。

### 对比方法
- 涵盖三类 VLA：
  - 离散 token 类：Octo、OpenVLA
  - 生成式动作头类：π0-FAST、π0、π0.5-KI、SmolVLA
  - 定制架构类：MolmoAct、OpenVLA-OFT
- 关键对照：VLA-0（同策略骨架的最近基线）以及 **VLA-0 w/ Naive ICL**（关闭 Target Action Masking、控制变量最严的对照）。
- 概念性讨论：REGENT、RICL、MEM、KARAG、Instant-Fold。

### 评估指标
- 成功率（SR）为主指标；模拟每个任务跑 10 个随机初始化回放；真实每个任务 250 次试验（共 1,000 次）。
- Wilson 95% 置信区间。
- 直接检索评测：Recall@1/Recall@5，以离线 DTW 定义的 `P⁺` 为相关性目标。

## 6. 主要结论与发现

- **LIBERO**：平均 SR **97.7%**，高于 OpenVLA-OFT（96.4%）；在 Spatial/Goal/Long 均为最佳，Long 任务提升 +3.6 pp。
- **RoboTwin 2.0**：平均 SR **60.4%**，比最强基线（OpenVLA-OFT 41.1%）高 **+19.3 pp**；Easy / Hard 分别提升 +17.2 / +21.8 pp。
- **真实任务**：4 任务平均 **83.2%**（95% CI 80.8–85.4），显著优于 π0（66.4%）与 VLA-0（63.0%）。
- **控制变量证据**：相同策略骨架、相同轨迹划分与检索上下文下，VLA-0 w/ Naive ICL 在 RoboTwin 2.0 仅 10.7%，而 ICI-VLA 达 60.4%，说明 Target Action Masking + 时空检索的组合是关键。
- **检索质量**：Recall@1 从基础嵌入的 27.8% 提升至完整 RD-Encoder 的 70.8%（+43.0 pp），Recall@5 从 52.4% → 90.1%（+37.7 pp）。
- **超参结论**：`N_e=3` 与 `N_iter=5` 为验证集上效果峰值且成本最小（并未在测试集上调参）。

## 7. 优点

- **范式创新**：明确把"任务级参数更新"替换为"测试时检索-条件化"，并将 offline 训练与 test-time 推理严格分离。
- **架构极简**：基于 VLA-0 的纯文本动作接口，**不加任何动作头或额外模块**，部署与训练工程开销低。
- **检索对齐设计**：语义硬过滤 + DTW 几何排序同时保证语义与相位一致，缓解时间混叠与语义-动态失配问题。
- **Target Action Masking**：训练时随机破坏上下文动作 token，直接抑制"动作前缀复制"捷径，迫使模型依赖当前观测。
- **实验体系较完整**：主表 + 消融 + 敏感性 + 检索直接评测 + 真实任务 + 置信区间，且控制变量版本（VLA-0 w/ Naive ICL）做到同骨架同检索同数据划分。
- **真实部署证据**：4 任务 × 250 次真实回放并报告 Wilson 区间，统计较扎实。
