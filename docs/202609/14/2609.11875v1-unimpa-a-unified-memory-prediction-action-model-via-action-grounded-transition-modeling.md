## 摘要
近年来，视觉-语言-动作（VLA）模型的研究进展推动了机器人操控能力的提升，但由观测到动作的学习仍受限于一个根本性的转移可实现性差距，该差距体现在三个紧密耦合的问题上：（i）转移模糊性。视觉上相似的当前观测可能对应不同的操控阶段，并暗示不同的后续转移。（ii）预测与执行的不一致性。视觉上合理的未来观测预测并不一定对应于物理上可实现的转移。（iii）经验与实现的不一致性。历史上可执行的动作模式未必能在当前场景中实现预期的转移，因此需要根据上下文进行自适应调整。为此，我们提出了 UniMPA——一种统一的记忆-预测-动作模型，通过一个共享的、以动作引导的转移接口来应对上述问题。（i）UniMPA 引入了持久-选择性未来预测机制，通过建模预期未来状态的演化来缓解转移模糊性。其中，持续的潜变量流持续追踪任务级别的进展，而转移关键像素流则通过基于记忆的预测，选择性地解析细粒度的交互变化。（ii）为了评估预期转移的物理可执行性，所预测的转移会查询一个时序视觉-动作记忆库。该记忆库检索历史上已实现的视觉-动作经验，将未来预测锚定于可执行的证据之上。（iii）为了将可执行经验适配到当前场景，动作-视觉记忆库从历史动作演化中检索由视觉引导的动作原型。随后，原型偏置流将流动源向由历史支持的动作流形偏移，以实现基于上下文的精细化调整。

## Abstract
Recent advances in Vision-Language-Action (VLA) models have improved robotic manipulation, yet observation-to-action learning remains limited by a fundamental transition realizability gap, manifested in three tightly coupled problems: (i) Transition ambiguity. Visually similar current observations may correspond to different manipulation phases and imply different subsequent transitions. (ii) Prediction--execution mismatch. A visually plausible predicted future observation does not necessarily correspond to a physically realizable transition. (iii) Experience--realization mismatch. A historically executable action pattern may not necessarily realize the intended transition in the current scene and therefore requires context-aware adaptation. Accordingly, we propose UniMPA, a Unified Memory-Prediction-Action model that addresses these problems through a shared action-grounded transition interface. (i) UniMPA introduces Persistent-Selective Future Prediction to resolve transition ambiguity by modeling the intended future state evolution. A persistent latent stream continuously tracks task-level progress, while a transition-critical pixel stream selectively resolves fine-grained interaction changes through memory-grounded prediction. (ii) To assess the physical executability of the anticipated transition, the predicted transition queries a temporal Visual-Action Memory Bank. The bank retrieves historically realized visual-action experience, grounding future prediction in executable evidence. (iii) To adapt executable experience to the current scene, an Action-Visual Memory Bank retrieves visually grounded action prototypes from historical action evolution. Prototype-Biased Flow then shifts the flow source toward a historically supported action manifold for context-aware refinement.

# UniMPA 论文总结

## 一、核心问题与研究动机

论文聚焦**机器人操控中视觉-语言-动作（VLA）模型的根本性瓶颈——"转移可实现性差距"（Transition Realizability Gap）**。作者指出，VLA 模型的核心难题不是简单的"观测→动作"映射，而是要推断任务相关的视觉转移并将其通过物理可执行的动作模式实现。

论文将这一高层科学问题分解为三个紧密耦合的子问题：

- **转移模糊性（Transition Ambiguity）**：视觉上相似的当前观测可能对应不同的操控阶段（如 T 恤折叠中的"起始折叠"与"继续折叠"），隐含不同的后续转移和动作模式。仅靠静态视觉观测无法可靠地区分任务意图。
- **预测-执行不匹配（Prediction-Execution Mismatch）**：视觉上合理的未来观测预测并不一定对应物理上可实现的转移，预测与动作演化之间缺乏统一的耦合接口。
- **经验-实现不匹配（Experience-Realization Mismatch）**：历史场景中可执行的动作模式未必能在当前几何与接触条件下直接复用，需要根据上下文进行自适应调整。

作者认为，现有的预测范式将未来预测与历史可执行性解耦，而记忆范式以观测为中心，缺乏"转移-动作"的对应关系。因此需要一种**统一的、面向"动作引导的转移"（Action-Grounded Transition）接口**，将预测、记忆与动作生成统一到同一物理转移表征上。

## 二、方法论

### 2.1 整体框架：Anticipate–Ground–Refine 流程

论文提出 **UniMPA（Unified Memory-Prediction-Action）** 模型，采用**三系统架构**：

1. **VLM 骨干**（PaliGemma-2B + 311M Gemma Action Expert，沿用 π0.5）
2. **World Expert（世界专家）**：18 层 Transformer，16 个可学习的零初始化转移查询（World Tokens），用于未来监督的转移表征学习
3. **Action Expert（动作专家）**：基于 Flow Matching 的动作生成模块

三个系统通过层级的块状注意力掩码（block-wise attention mask）实现层间共享自注意力，World Expert 在训练与推理中均参与计算。

### 2.2 三大核心模块

#### （1）持久-选择性未来预测（Persistent-Selective Future Prediction）

- **持久性潜变量预测**：World Expert 的转移 Token $Z^{tr}_t$ 通过轻量级预测头投影到 V-JEPA 2 潜空间，与未来观测的 V-JEPA 2 特征对齐（损失 $L_{lat}$），持续编码任务级进展。
- **选择性像素预测**：通过 **Transition-Critical Trigger Gate（转移关键触发门）** 决定何时启用像素解码头。门控信号由四类指标综合决定：
  - 潜变量语义变化分数 $r^{lat}_t$（V-JEPA 特征位移）
  - 平移变化指标 $b^p_t$
  - 旋转变化指标 $b^r_t$
  - 夹爪状态切换指标 $b^g_t$
- 像素预测的查询来自 World Token 的上采样，键/值来自 Visual-Action Memory Bank 检索到的视觉记忆值，仅在门激活时计算损失 $L_{pix}$。
- **关键设计**：未来观测不直接送入 Action Expert，而是用于**监督** World Token；解码头在推理时被丢弃。

#### （2）双记忆库预训练（Transition-Aligned Bidirectional Memory Pretraining）

在 Stage 1 预训练两个时序对齐的记忆库：

- **Visual-Action Memory Bank（视觉-动作记忆库）**：
  - 键：V-JEPA 2 特征投影 + ℓ2 归一化
  - 值：2 层有状态 Mamba 编码器，融合动作条件（S_a）和语义视觉 Token
- **Action-Visual Memory Bank（动作-视觉记忆库）**：
  - 键：最近动作历史的投影
  - 值：Mamba 编码器，融合多视角视觉动态

预训练损失包括三部分：

- $L_{rec}$：未来观测重建 + 未来动作块重建
- $L_{ret}$：检索模拟损失（用检索值解码未来，评估检索质量）
- $L_{pair}$：跨模态配对损失（InfoNCE 风格的双向视觉-动作对齐）

采用**粗到细时序检索（Coarse-to-Fine Temporal Indexing）**：先选最相关 episode，再在 episode 内做软检索，避免跨演示混淆不同时期。

#### （3）原型偏置流（Prototype-Biased Flow）

- 动作查询 $q_{a,t}$（基于近期动作历史）检索 Action-Visual Memory Bank 得到 $\bar{u}_{a,t}$。
- 与近期动作历史融合形成 **Action Proposer** 的原型 $P_{a,t}$。
- **核心创新**：检索到的原型不是作为最终动作直接复制，而是**平移（bias）Flow Matching 的源分布**：
  $$p(\tilde{\epsilon}_t | P_{a,t}) = \mathcal{N}(\lambda_p P_{a,t}, I)$$
- Action Expert 在该先验偏置的基础上，通过 Flow Matching 对当前视觉-语言上下文与世界转移表征进行迭代精炼，得到最终动作块。

### 2.3 训练目标

Stage 1：$L_{bank} = L_{rec} + \lambda_{ret} L_{ret} + \lambda_{pair} L_{pair}$
Stage 2：$L_{UniMPA} = L_{act} + \lambda_{lat} L_{lat} + \lambda_{pix} L_{pix}$

## 六、主要结论与发现

   - 真实世界（AgileX）TSR **74.9%** / CSR **86.4%**（超 π0.5 12.6/11.5 个百分点）
   - GALAXEA R1 Lite：TSR **77.7%** / CSR **86.3%**

2. **三大模块均不可缺**：消融显示移除记忆、性能下降最大（-13.8% TSR / -10.7% CSR）；移除触发门、退化为随机触发，性能下降 9.8%/7.3%。

3. **持久+选择性预测优于单一模式**：仅潜变量或仅像素均劣于组合设计；密集像素预测次之。

4. **双向记忆互补**：Visual-Action 与 Action-Visual 各自贡献不同（前者 -8.0%/-6.3%，后者 -6.9%/-5.0%）。

5. **时序建模关键**：在 LIBERO-Long 任务上，去除时序建模下降 6.0 个百分点。

6. **检索-复制不可取**：直接复制最近邻动作性能最差（-22.9%/-18.9%），证明"先验偏置+精炼"优于"复制"。

7. **训练效率**：仅需 25-50% π0.5 的训练 epoch 即可达到更优性能。

## 七、优点与亮点

1. **理论贡献突出**：明确提出"转移可实现性差距"这一高层科学问题，并分解为三个紧密耦合的子问题，给出系统化解决思路。
2. **统一框架**：将预测、记忆、动作三者在"动作引导的转移"接口下统一，相比现有"分开设计"的方法更具系统性与可解释性。
3. **三系统架构**：VLM + World Expert + Action Expert 的层级注意力设计，使 World Token 在训练与推理中均参与动作生成（区别于传统仅作为辅助监督的设计）。
4. **记忆设计精巧**：
   - 视觉-动作双向记忆库对应两个查询方向
   - 有状态 Mamba 建模时序动态
   - 跨模态配对损失建立视觉-动作对应
   - 粗到细检索避免跨演示混淆
5. **持久-选择性预测**：避免了密集像素预测的冗余与重建偏差，同时结合潜变量与关键像素两层级监督。
6. **Prototype-Biased Flow**：优雅地将检索经验转化为流形先验偏置而非直接复制，保留了 Flow Matching 的生成灵活性。
7. **实验规模庞大**：仿真 + 真实双平台、525+ 真实试验、6 组消融、可视化充分，可复现性强。
8. **效率优势**：仅用 25-50% 训练 epoch 即可超越 π0.5，具实用价值。

## 八、不足与局限

1. **语料与基线公平性**：论文提到大多数真实世界对比基线由其自行复现（标注†），结果可能受复现实现差异影响（虽然尽力保证公平）。
2. **异步记忆更新限制（作者自述）**：当前轮次内收集的经验只能用于**未来** rollout，无法即时回用于当前执行，缺乏在线持续记忆能力。
3. **固定时间尺度**：潜变量预测、像素预测、记忆检索、动作生成均采用固定的未来偏移 Δ 和动作视野 K，无法根据任务阶段动态调整。
4. **二值触发门**：Trigger Gate 仅做"激活/不激活"二元判断，无法根据转移不确定性动态分配计算资源（作者已列为未来工作）。
5. **单原型动作先验**：当前仅检索单一原型作为流形偏置，未建模操控中常见的多模态动作分布（如不同的抓取方向、恢复策略）。
6. **跨平台泛化仍有挑战**：在某些长程任务（Suite G Folding Recovery）和 RoboTwin 2.0 中部分任务（如 Handover、Stack）仍存在失败案例。
7. **依赖 π0.5 架构**：方法在很大程度上继承 π0.5 的双系统骨架，迁移到其他 VLA 架构（如纯自回归或单系统）的工程成本未评估。
8. **真实世界任务定义较"演示化"**：所有任务为预设动作序列化的检查点序列，与完全开放环境下的自主探索仍有差距。
9. **训练算力信息略粗**：仅给出 GPU 型号与数量，未给出总训练时长（小时数）和碳排放等更精细的算力指标。
10. **触发行人讨论中提到的伦理与安全考量未涉及**（虽属于机器人操控领域的重要议题，但本文聚焦技术本身）。
