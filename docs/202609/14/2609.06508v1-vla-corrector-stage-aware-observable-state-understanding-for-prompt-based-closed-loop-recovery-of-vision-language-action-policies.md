## 摘要
使用视觉-语言-动作（VLA）策略进行长时序机器人操作仍然容易受到执行时偏差的影响，因为最终任务是否成功所提供的信息很少，难以用于诊断和修正由动作噪声、物体位移或目标错位引起的失败。我们提出了一种阶段感知的失败验证与提示恢复框架，能够在不进行参数更新或访问特权模拟器状态的情况下，对固定的VLA策略进行闭环修正。该框架引入了一种基于可观测历史的学习验证器，通过对多视角视觉观测、本体感知状态和已执行动作进行时序建模，联合估计操作进度和执行风险。为了提供可解释的任务理解，我们通过语义进度阶段来表征操作执行过程，包括接近、对齐、抓取、搬运和放置，并识别特定阶段的失败模式。在检测到异常执行时，该框架保留原始指令并生成一个阶段条件化的恢复提示，使同一冻结的VLA策略能够产生修正动作。在LIBERO和LIBERO Plus上进行的广泛多轮评估表明，所提出的方法在多样化扰动下显著提升了闭环可靠性。在无法访问特权物体或目标坐标的情况下，学习验证器在所评估场景中的恢复性能接近特权基于规则验证器的水平。这些结果表明，可观测的视觉-本体感知-动作历史足以推断潜在的任务状态，并为现有VLA策略实现实用的失败恢复。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

## 一、核心问题与研究动机

- **核心问题**：长时序机器人操作中，基于动作分块（action chunking）的 VLA 策略在执行时容易因动作噪声、目标物体位移或目标区域偏移等累积偏差而失败；而"任务最终成败"这一稀疏信号无法用于诊断失败原因，也难以触发有效恢复。
- **研究缺口**：现有 VLA 模型擅长"知道该做什么"，但缺乏"知道当前是否做对"的执行状态感知能力，导致其无法识别和修正执行偏差。
- **核心假设/研究问题**：能否仅依靠可观测的交互历史（视觉、本体感知、执行动作）来推断潜在任务状态，并在不修改 VLA 参数、不访问特权环境信息的前提下实现闭环失败恢复？
- **整体含义**：将"执行状态理解"与"动作生成"解耦，在冻结的 VLA 策略之上构建一个轻量级的"监控—纠正"模块，使已有 VLA 模型获得实用的失败恢复能力。

## 二、方法论

### 1. 整体框架（VLA-Corrector）
闭环流程：**观测 + 指令 → π0.5 冻结策略 → 动作分块 → 风险验证器 → 触发门控 → Prompt Recovery → 任务恢复**。每次控制周期，策略输出动作分块但只执行前缀（replan_steps=5），随后由验证器基于最新可观测历史评估执行状态。

### 2. 关键模块

- **基础策略（Base π0.5 Policy）**：使用预训练的 OpenPI `pi05_libero` 策略，全程冻结，不更新参数、视觉编码器或动作头。观测渲染为 256×256 后缩放至 224×224，动作维度为 7。
- **特权规则验证器（Privileged Rule-Based Verifier）**：作为"性能上界"，基于仿真器真值（物体/区域位姿、末端运动学、距离、夹爪状态、BDDL 谓词、任务标志），维护状态机 `APPROACH → ALIGN → GRASP → MOVE → PLACE → SUCCESS`，仅在非终态阶段触发恢复。
- **学习验证器（Learned Verifier）**：核心可部署模块，输入包括：
  - 2 视角 RGB（agent view + wrist view，112×112）
  - 8 维本体感知状态
  - 7 维已执行动作
  - 8 步历史窗口（每 2 步采样一次）
  
  架构特点：
  - 视觉分支为**无参数空间统计特征器**（自适应平均池化 3×4×4 + RGB 均值/标准差 → 每视角 54 维 → 拼接投影 64 维）
  - 状态-动作向量投影至 32 维
  - GRU（隐藏维度 64）做时序融合
  - 两个预测头：二值执行风险头 $p_t = \sigma(w_f^\top z_t + b_f)$ 与 5 阶段分类头 $\hat{c}_t = \arg\max\, \text{Softmax}(W_{\text{stage}} z_t + b_{\text{stage}})$
  
  训练时仅使用由特权信号生成的离线教师标签（阶段标签 + 二值风险标签，距离失败事件 ≤10 步标为正、>20 步标为负，模糊区间排除），**不回归特权坐标**。

- **在线触发门控（Online Trigger Gate）**：阈值 τ=0.40 + 连续 4 帧确认 + 10 步冷却期，每 2 步查询一次，用于抑制误报并避免重复干预。
- **Prompt Recovery（提示恢复）**：保留原始任务指令 $q$，拼接"Immediate recovery: "前缀与阶段路由的恢复指令片段 $r_t$（如接近、抓取等），形成 $q^{\text{rec}}_t = q \oplus r_t$；低置信度（<0.9625）则使用通用 UNKNOWN_FAILURE 提示。**所有恢复动作仍由冻结 π0.5 生成**，恢复结束后立即恢复原指令 $q$。

### 3. 关键设计理念
- **策略无关（policy-agnostic）**：不微调 VLA、不增加动作头、不直接修改轨迹，仅作为"可复用控制器"的轻量接口。
- **特权解耦**：训练阶段用特权信号生成教师标签，部署阶段仅依赖可观测序列。
- **阶段语义化**：把"风险检测"与"阶段路由"分离——阶段头只作为恢复指令路由器，而非五类风险检测器。

## 三、实验设计

### 1. 数据集 / 仿真基准
- **标准 LIBERO**：LIBERO-SPATIAL、LIBERO-GOAL、LIBERO-OBJECT、LIBERO-10、LIBERO-90。
- **LIBERO Plus**：在 Spatial / Goal / Object / 10 套件上分别设置 difficulty 4 和 difficulty 5 两个难度等级。

### 2. 扰动协议（控制变量评估）
- **Clean**：无扰动。
- **Action Noise**：对归一化动作添加 σ=0.1 的零均值高斯噪声。
- **Target-Object Shift**：目标物体 XY 坐标位移 0.1 m。
- **Goal-Region Shift**：目标区域 XY 坐标位移 0.1 m。
- **Combined**：三种扰动同时施加（`action_noise_std=0.1, image_noise_std=0.0, perturb_target_xy=perturb_goal_xy=0.1`）。
- 仿真上限：每回合 280 步，单次 Prompt Recovery 最多 100 步。

### 3. 对比方法（三种匹配设置）
| 配置 | 在线验证器 | Prompt Recovery |
|------|------------|------------------|
| **No Assistance** | 无，原始冻结策略 | 无 |
| **Rule + Prompt** | 特权规则验证器（性能上界） | 共享接口 |
| **Learned Binary + Prompt** | 学习验证器（无可特权信息） | 共享接口 |

### 4. 真实世界评估
- 物理机器人平台，三项任务：**Pick and Open（抓取并打开玩具抽屉）**、**Place（将木块放入四格盒）**、**Pour Water（抓取塑料瓶倒水）**。
- 在执行中段人为改变目标物体位置以模拟扰动，每任务 40 次独立试验。
- 使用与仿真完全相同的冻结 π0.5 策略和闭环纠正框架，**未使用任何真实数据微调策略或重新训练验证器**。

### 5. 评估指标
- 主要：**回合成功率**（Success Rate，1000 episodes / 标准 LIBERO 条件）。
- 验证器：**Accuracy、Precision、Recall、Positive F1、AUROC、AUPRC**。
- 闭环组件：触发门控质量、恢复成功率、动作成本、推理延迟（p50/p95）。

## 六、主要结论与发现

1. **Prompt Recovery 一致提升闭环可靠性**：标准 LIBERO 平均成功率从 70.9% 提升至 82.6%（Rule + Prompt）/ 80.2%（Learned）；增益在目标位移与组合扰动下尤为显著（+11.7 pp / +9.3 pp）。
2. **学习验证器逼近特权上界**：在标准 LIBERO 与 LIBERO Plus（difficulty 4/5）上，Learned Binary + Prompt 与 Rule + Prompt 的差距仅 ~2.4 pp，表明可观测历史足以估计执行风险与阶段。
3. **可观测历史足以推断潜在任务状态**：仅依靠视觉—本体—动作时序序列即可支撑恢复决策，无需特权物体或目标坐标。
4. **时序融合是关键**：Temporal + Fusion 在 Positive F1（74.35）、Recall（94.85%）上显著优于单帧（59.33 / 75.49%）与单模态输入；State-action only 最弱（58.55），说明本体/动作单独不足以支撑判断。
5. **真实世界有效迁移**：3 类任务平均成功率 88.3%，相比冻结 π0.5 基线 82.5% 提升 5.8 pp。
6. **检测组件与恢复组件可分离评估**：触发精度 79.2%，恢复成功率 75.0%~77.0%，验证了 Prompt Recovery 接口的通用性。

## 七、优点与亮点

- **范式创新**：把"策略不可知、轻量、非侵入"的监控—恢复模块嫁接到冻结 VLA 上，避免修改底层策略或引入额外动作头，对实际部署友好。
- **特权解耦思路**：训练用特权信号、部署仅靠可观测输入，既保证监督信号质量又保证可部署性。
- **阶段语义化设计**：5 个非终态阶段（APPROACH/ALIGN/GRASP/MOVE/PLACE）使恢复提示具备可解释性与针对性，而非笼统的"重新尝试"。
- **验证器极轻量**：无参数视觉特征器 + 小型 GRU，CPU 上亚毫秒级延迟，易于实际系统嵌入。
- **评估协议系统化**：明确的可复现扰动协议、5 类扰动、多基准层级、统一对照方法，实验公平性较好。
- **仿真+真机双验证**：仿真多轮评估 + 真实机器人迁移，表明方法具备实践可迁移性。

## 八、不足与局限

- **算力与训练细节缺失**：未报告 π0.5 推理所需的 GPU 资源、收集 120 个回合训练验证器的算力开销，整体系统运行成本不透明。
- **学习验证器训练集规模有限**：仅 120 episodes（60% train ≈ 72 episodes），且为 episode-disjoint 划分；如此小规模下达到 93% 准确率，泛化到更复杂任务与新场景的能力尚存疑。
- **二值检测精度偏低**：Precision 仅 61.14%，虽然 Recall 高达 94.85%，但 Positive F1 仅 74.35；AUPRC 0.7123 表明正负样本不均衡场景下仍有挑战。
- **阶段头置信度阈值偏高**：0.9625 的高阈值意味着多数情况下实际走 UNKNOWN_FAILURE 通用恢复，分阶段路由的实际贡献未被充分评估。
- **消融覆盖不全面**：未对恢复提示措辞、确认窗口 k、冷却期长度、阈值 τ 等关键超参数做敏感性分析。
- **真实世界覆盖有限**：仅 3 类任务、每任务 40 次，且为单一平台；未涉及更长时序、更强接触操作、多阶段连锁任务。
- **应用假设较强**：依赖 action chunking 与固定 replan 步长（5/3），对其他执行模式（如扩散策略连续重规划、低频长分块）的适用性未验证。
- **扰动类型与现实差距**：仿真扰动为受控位移/噪声，未涵盖真实场景中的遮挡、光照变化、物体形变、新物体出现等开放世界偏差。
- **教师信号依赖**：阶段与风险标签仍需特权仿真信号离线生成，对真实场景中无特权信号的任务标签构造未给出解决方案。
- **方法适用范围限定**：仅在 π0.5/LIBERO 范式下验证，对更早期 VLA（如 RT-2、OpenVLA）或其他机器人平台的迁移性尚不明确。
