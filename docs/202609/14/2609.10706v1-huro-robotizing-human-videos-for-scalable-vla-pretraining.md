## 摘要
人类视频数据集作为昂贵的真实机器人数据之外的一种引人注目的替代方案，以可扩展的方式提供了丰富的多样性。为了弥合人体与机器人之间的本体差异，现有方法要么在任务匹配的环境下将视频机器人化，要么在大规模下分别处理观测与动作的对齐。在本工作中，我们系统地研究了机器人化的人类视频能否为视觉-语言-动作（VLA）策略的预训练提供有效且可扩展的监督。为此，我们开发了一条机器人化流水线，可将异构的人类视频转换为与机器人对齐的观测和动作轨迹，同时在不同的标注层级之间推断缺失的中间信号。利用该流水线，我们构建了 HuRo 数据集，包含来自五个人类视频源的约 63 万个机器人化回合和 1.42 亿个处理后的帧。在四个真实世界操作任务上，机器人化预训练规模的扩大将总体完成率从 51.5% 提升至 80.3%，并在空间与视觉偏移下的分布外（OOD）完成率从 34.9% 提升至 72.2%。消融实验进一步表明，视觉机器人化提升了 OOD 鲁棒性，并且结合重定向动作的端到端预训练优于仅视觉的迁移。代码与数据已在我们的网站上发布：https://3587jjh.github.io/HuRo。

## Abstract
Human video datasets have emerged as a compelling alternative to expensive real-robot data, offering rich diversity at scale. To bridge the human-to-robot embodiment gap, existing approaches either robotize videos in task-matched settings or address observation and action alignment separately at scale. In this work, we systematically examine whether robotized human videos can provide effective and scalable supervision for pretraining vision-language-action (VLA) policies. To this end, we develop a robotization pipeline that converts heterogeneous human videos into robot-aligned observations and action trajectories while inferring missing intermediate signals across annotation levels. Using this pipeline, we construct the HuRo dataset, comprising about 630K robotized episodes and 142M processed frames from five human-video sources. Across four real-world manipulation tasks, increasing robotized pretraining scale improves overall completion from 51.5% to 80.3% and OOD completion under spatial and visual shifts from 34.9% to 72.2%. Ablations further show that visual robotization improves OOD robustness and that end-to-end pretraining with retargeted actions outperforms visual-only transfer. Code and data are released on our website: https://3587jjh.github.io/HuRo.

# HuRo 论文详细总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）策略的能力随预训练数据规模增长而提升，但真实机器人数据采集成本高昂且规模受限。人类视频数据具有规模大、场景/视角/行为多样的优势，是替代真实机器人数据的有力来源。
- **核心挑战**：人与机器人之间存在显著的**本体差异（embodiment gap）**，涵盖观测（人类手部 vs. 机器人形态）与动作（人手运动 vs. 机器人关节轨迹）两方面。
- **现有方法不足**：
  - 联合观测-动作机器人化方法（如 Phantom、DexUMI、WARPED、RwoR、MimicDreamer）多在**任务匹配**场景下验证，难以作为通用预训练数据；
  - 大规模方法要么仅做视觉机器人化用于表征学习（H2R、Masquerade），要么保留人类观测而只重定向动作（VITRA、EgoScale），未能**同时**实现观测与动作的大规模机器人化对齐。
- **本文研究问题**：将异构人类视频进行**联合观测-动作机器人化**，并大规模用于 VLA 预训练，是否能提供有效且可扩展的监督？

---

## 2. 方法论

### 2.1 整体框架
设计了一条三阶段**机器人化流水线**，将异构第一人称人类视频转换为机器人对齐的（观测、状态、动作、语言指令）四元组。

### 2.2 三阶段流水线

#### 阶段一：人类视频标注
- **相机内参估计**：使用 droidcalib（运动场景） / AnyCalib（近静态场景），校正为针孔图像；
- **手部检测与跟踪**：100DoH 逐帧检测手部 + BOT-SORT 时序优化左右手分配；
- **手部姿态估计**：HAWOR + MANO 模型，逐帧估计左右手 3D 手部姿态 $P_t^h$；
- **相机轨迹估计**：masked DROID-SLAM（排除手部区域）+ MoGe-2（度量尺度恢复）+ GeoCalib（重力对齐），获得度量级相机到世界变换 $T^{W\leftarrow C_{src}}_t$；
- **切片与语言标注**：将操作片段切成固定长度块（chunk），将腕部轨迹投影到 RGB 帧上后由 Qwen3.5 生成语言指令 $l_i$，并做一致性校验。

每个标注块可表示为：$H_i = \left(\{I_t\}, K, \{T^{W\leftarrow C_{src}}_t\}, \{P_t^h\}_{h\in\{L,R\}}, l_i\right)$

#### 阶段二：动作转换（运动重定向）
- 使用 **PyRoKi** 在两阶段优化框架下将人手运动重定向为机器人关节轨迹：
  - **稀疏阶段**：在采样时间步上联合优化世界→机器人基座对齐变换 $T^{B\leftarrow W}_{\xi_i}$（3D 平移 + 偏航）与关节配置 $q_t$，目标函数包括指尖位置、局部手部结构、ego-view 一致性、关节限位与静止位姿正则；
  - **稠密阶段**：固定对齐后，对完整时间步 $\{q_t\}_{t=0}^{T_i-1}$ 重新优化，加入时序平滑项；
- 通过前向运动学得到策略状态序列 $\{s_t\}$，动作目标定义为 $a_t = s_{t+1}$（末帧复制）。

#### 阶段三：视觉转换
- **人体去除**：SAM2（+ Detectron2 辅助提示）分割手臂区域 → ProPainter 视频修复 → 得到 $\bar{I}_t$；
- **机器人叠加**：使用 Isaac Sim 渲染目标机器人，根据同一对齐变换 $T^{B\leftarrow W}_{\xi_i}$、相机内参 $K$、关节配置 $q_t$ 将机器人合成到清洁帧上，得到 $\tilde{I}_t$；
- 最终 episode：$E_i = \{(\tilde{I}_t, s_t, a_t, l_i)\}_{t=0}^{T_i-1}$。

### 2.3 数据集与目标机器人
- **HuRo 数据集**：约 **63 万集、1.42 亿帧**（约 1317 小时 @30fps），来自 5 个源：EgoDex（56%）、EgoVerse（27%）、Ego4D（10%）、Ego10K（6%）、EPIC-Kitchens（2%）；
- **目标机器人 ALLEX**：双臂 7-DoF × 2 + 双手 15-DoF × 2 + 2-DoF 颈 + 2-DoF 腰。

### 2.4 VLA 策略训练
- **架构**：基于 GR00T-N1.6-3B，末端执行器（EEF）式动作接口；
- **动作表示**：左右腕部相对位姿（3D 平移 + 6D 旋转）+ 左右手绝对关节目标，预测 H=40 步动作块；
- **训练**：Flow-matching 目标，VLM 视觉编码器联合微调；预训练 80k 步、全局 batch size 2048、AdamW（lr=1e-4，wd=1e-5）；下游微调 30k 步、batch size 128、cosine 衰减。

## 3. 实验设计

### 3.1 数据集与场景
- **真实机器人任务（4 项，ALLEX 平台）**：
  1. **Apple Pick-and-Place**（43 演示）：单臂抓取苹果放入碗中（ID 12 + OOD 12 rollout）；
  2. **Cup Stacking**（40 演示）：单手举起初始杯堆，另一手逐个叠加两杯，再放回桌面（ID 12 + OOD 24）；
  3. **Cup-Noodle Handover**（16 演示）：双手交接杯面并放置到目标架（ID 12 + OOD 12）；
  4. **Microwave Loading**（20 演示）：开门、放入杯面、关门（仅 OOD 10 rollout）。
- **OOD 设定**：空间布局偏移（物体位置变化）和视觉外观偏移（棋盘桌布、新背景、新物体实例）；
- **附加任务**：Diverse Pick-and-Place（36 ID + 18 OOD）、OpenArm Fruit Pick-and-Place（评估跨本体迁移）。

### 3.2 对比方法
- **参考基线**：π0.5、GR00T N1.6（保留预训练动作头直接微调）；
- **受控变体**：
  - 0% / 10% / 50% / 100% PT（不同预训练规模，保持源数据比例）；
  - **no-overlay**（100% 预训练但保留人类原视频观测，仅使用重定向动作监督）；
  - **Visual-only**（仅迁移视觉通路，重初始化动作头）；
  - **Visual+Action**（端到端预训练，全量迁移）。
- **视频生成对比**：I2V + IDM（DreamGen 风格），在 0.7M / 3.5M / 7.0M 帧预算下与 HuRo 对比；
- **附录对比**：Masquerade 风格机器人化、Human-HRDT、Human-VITRA（人类域预训练），以及多本体联合预训练（ALLEX + OpenArm）。

## 4. 资源与算力

- **流水线处理**：单卡 **RTX 5090**，每段 15 分钟原始视频处理耗时约为源视频时长的 **8–10 倍**（如 EPIC-Kitchens 9.5×，Ego4D 8.0×），其中人类视频标注占主要开销，机器人重定向与叠加仅占总成本的约 5–11%；
- **预训练算力**：80k 步、batch size 2048，文中未明确给出 GPU 数量或总 GPU 小时；声明由合作单位 **RLWRLD** 提供 ALLEX 平台访问与计算资源；
- **下游微调**：30k 步、batch size 128；
- **总实验规模**：约 1316.8 小时处理后数据 + 4 个真实任务评估（含 ID/OOD 多种 rollout） + 多个消融与跨本体实验。

## 5. 实验数量与充分性

- **主实验**：5 个预训练规模变体（0/10/50/100% PT）+ 1 个 no-overlay 变体 + 2 个参考模型，跨 4 个真实任务 × ID/OOD 设置；
- **消融实验**：
  - 视觉机器人化效果（no-overlay vs. full HuRo）；
  - 端到端 vs. 仅视觉迁移（No PT / Visual-Only / Visual+Action）；
  - 与 Masquerade 风格机器人化的对照（Appendix B）；
  - 与人类域预训练 Human-HRDT / Human-VITRA 对照（Appendix C）；
  - 跨本体迁移（OpenArm, Appendix E）；
  - 多本体联合预训练（ALLEX+OpenArm）；
  - 与视频生成式预训练（I2V+IDM）的多预算对比；
- **数据集分析**：源构成比例、可视化覆盖（DINOv3 vs. OpenImages）、指令覆盖（动词/宾语/动宾对）、流水线效率与质量诊断（Appendix F：相机轨迹、手部姿态、重定向、关节限位、自碰撞、修复质量等量化指标）；
- **公平性**：所有受控变体统一 VLM 初始化（GR00T-N1.6-3B）、统一动作头从零初始化、相同预训练步数与 batch size、相同下游微调流程；
- **总体评价**：实验覆盖**较充分**，从规模效应、各组件贡献、跨本体迁移、与多类基线对比到数据质量诊断均涵盖；但所有任务在单一 ALLEX（双臂灵巧机器人）平台完成，跨硬件平台泛化仍需进一步验证。

## 6. 主要结论与发现

- **规模效应显著**：随着预训练规模从 0% 提升到 100%：
  - 平均整体完成率：**51.5% → 80.3%**；
  - 平均 ID 完成率：**68.1% → 88.4%**；
  - 平均 OOD 完成率：**34.9% → 72.2%**；
- **超越参考基线**：在 ID 与 OOD 设置下均优于 π0.5 和 GR00T N1.6；
- **视觉机器人化的价值**：full HuRo（88.4% ID / 72.2% OOD）vs. no-overlay（89.4% ID / 55.7% OOD）——ID 接近但 **OOD 显著提升**，且 10% PT 的 OOD（59.5%）已超过 no-overlay 满量级；
- **端到端预训练的重要性**：Visual+Action（ID 61.1% / OOD 50.0%）远优于 Visual-Only（ID 31.9% / OOD 25.0%）和 No PT（ID 13.9% / OOD 13.9%），证明动作监督本身带来远超视觉表征学习的收益；
- **混合源优于单源**：50% 混合源（71.1M 帧，ID 78.2% / OOD 69.8%）超过全量 EgoDex 单源（78.9M 帧，ID 63.9% / OOD 54.2%）；
- **优于视频生成式预训练**：HuRo 0.7M 帧即超过 I2V+IDM 7.0M 帧，扩展优势随预算扩大而扩大，尤其 OOD 增益显著；
- **跨本体可行性**：ALLEX 训练的 HuRo 预训练可迁移到 OpenArm，并在 OOD 上取得最佳整体表现；联合多本体预训练（ALLEX+OpenArm）效果优于单本体。

---

## 7. 优点与亮点

- **大规模 + 系统性**：将机器人化从"任务匹配演示"提升到"通用预训练数据"层级，630K 集 / 142M 帧规模在同类工作中领先一个数量级；
- **联合观测-动作机器人化**：同时在视觉和运动层面与目标机器人对齐，并补全不同标注源缺失的中间信号，兼容异构数据；
- **流水线模块化设计**：以世界→基座对齐变换 $T^{B\leftarrow W}_{\xi_i}$ 为枢纽，**同时驱动动作重定向和相机-机器人叠加**，共享相机轨迹，避免观测-动作不一致；
- **端到端 VLA 预训练**：与以往多用于表征学习或辅助任务的机器人化方法形成对比，证明动作监督的独特价值；
- **实验设计全面**：包含规模、组件、跨本体、与多种基线（含视频生成式和人类域）的多维比较，并提供流水线效率与质量诊断；
- **数据/代码公开**：发布 HuRo 数据集与流水线，便于复现与扩展；
- **多本体通用性**：流水线与目标机器人解耦，可应用于 ALLEX、OpenArm、RBY1、GR1 等不同形态的机器人。

---

## 8. 不足与局限

- **机器人叠加保真度有限**：未显式建模渲染机器人与场景几何的遮挡关系，可能引入视觉不一致；附录显示相机-机器人对齐残差在 1% 尾部仍较大；
- **无接触/力/触觉信号**：仅提供视觉与运动学动作监督，缺少力/触觉反馈，难以处理接触密集型操作；
- **重定向运动学简化**：未建模自碰撞与物理接触，5 个源审计中仅 55.2% 的轨迹在采样帧中无检测到的非抓握自接触，重定向结果更适合作为预训练监督而非可执行演示；
- **流水线成本较高**：处理耗时约为源视频的 8–10 倍，单卡成本对大规模扩展构成瓶颈；
- **残存人工痕迹**：inpainting / 渲染 artifact 可能引入视觉偏差，且对策略学习的具体影响未做系统化研究；
- **评估平台单一**：主要实验均在 ALLEX 上完成，跨硬件平台（不同自由度、关节构型）的泛化结论仍需更广泛验证；
- **任务覆盖偏窄**：4 个真实任务（仅 Pick-and-Place、Handover、Stacking、Microwave Loading）尚不足以覆盖长尾操作场景；
- **算力披露不充分**：预训练 GPU 型号/数量/总时长未明确给出，难以复现精确的算力成本。
