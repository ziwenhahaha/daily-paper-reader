# ComVLA: Communication-Aware Split Inference for VLA Models in 6G-Connected Robotics 

Boliang Liu ∗† , Wint Yi Poe †, Jingyun Di ∗† , Riccardo Trivisonno † and Giuseppe Caire ∗∗Technical University of Berlin, Berlin, Germany 

†Huawei Heisenberg Research Center, Munich, Germany Emails: boliang.liu@campus.tu-berlin.de; {wint.yi.poe, jingyun.di, riccardo.trivisonno}@huawei.com; caire@tu-berlin.de 

Abstract —Connected robotics is an emerging 6G application where mobile robots follow natural-language instructions to manipulate physical objects. The Vision-Language-Action (VLA) models that enable this are too large to run on the robot; a common trend is to offload inference to the cloud. The wireless link, however, limits how much sensing data the edge can transmit per control step. Two recent lines address this constraint: semantic communication codecs compress sensor data but require channel-specific retraining, and VLA token pruners select tokens from image but ignore the channel. Our insight is that the dense semantic information contained in the language already indicates which visual tokens matter. We propose ComVLA, a framework that uses this language guidance to adapt the VLA token budget to the channel capacity. Transmitting 32 tokens instead of 512 on the LIBERO benchmark, ComVLA cuts inference compute by 74% 

and inference latency by 22% versus the original OpenVLA-OFT baseline, at a cost of 1.5 pp in average task success ( 95 .4% vs. 

96 .9% ), and it stays within the capacity budget under Rayleigh and Rician fading. These results demonstrate that co-designing VLA inference and wireless communication is a practical direction for 6G-connected robotics. 

Index Terms —Robotics, Semantic Communication, Token Prune, 6G Network, Token Communication 

I. Introduction Connected robotics is among the demanding applications envisioned for 6G networks [1], requiring low-latency, high-reliability communication between mobile robots and cloud infrastructure. Recent advances in large language models (LLMs) and vision-language models (VLMs) have driven a paradigm shift in robotics, from traditional perception-planning-control pipelines toward Vision-Language-Action (VLA) models. VLAs extend VLMs with an action head, mapping camera observations and natural-language instructions to low-level actions end-to-end. The large VLA parameter scale makes edge deployment impractical, motivating split inference across edge and cloud [2]–[4]. However, cloud offloading requires streaming high-dimensional visual features at each control step, which causes severe bandwidth bottlenecks over practical wireless channels. Yet recent findings identify a remedy: visual tokens are highly redundant in large vision-language models, and VLA action decisions depend on a sparse set of task-relevant visual regions [5], [6]. Two lines of work exploit this sparsity but each leaves a gap. Semantic communication (SemCom) [7] addresses the bandwidth mismatch by transmitting task-relevant features

Beyond SemCom, recent VLA token pruning methods [8] reduce inference computing by selecting visual tokens via language instructions, but assume a static token budget with no mechanism to adapt to dynamic wireless conditions. In this paper, we propose ComVLA (Communication-aware VLA), a split-inference framework that co-designs semantic token selection with the wireless channel, as illustrated in Fig. 1. Our key observation is that language instructions naturally identify the task-relevant visual tokens. ComVLA exploits this on the edge and dynamically sets the transmitted token budget to match the instantaneous channel capacity [9]. The contributions of this paper are:

> •

Mechanism - Semantic-guided token selection with a capacity-aligned token budget. We use language instructions to evaluate the task relevance of visual tokens and couple the transmitted token budget directly to the channel capacity, so the payload adapts to the channel in real time.

Semantic and Task-Oriented Communication. Deep-JSCC [10] pioneered wireless image transmission, and WITT [11] later extended it with transformers; a parallel line of task-oriented communication [7] targets task-level semantic objectives rather than pixel fidelity. These approaches all introduce dedicated codecs that require channel-specific retraining. 

VLA Models in Edge-Cloud Systems. VLA models demonstrate strong robotic manipulation capabilities but are too large for on-device inference. Such scale motivates split-computing paradigms [12] that partition inference between edge and cloud, yet existing frameworks still transmit raw visual features over bandwidth-limited channels and treat the link as a fixed pipe. ComVLA co-designs the split-inference token payload with channel capacity. 

Visual Token Pruning. Visual token pruning methods reduce inference costs but are channel-agnostic. FastV [13] shows up to half of visual tokens become redundant after the early transformer layers. For VLAs, LightVLA [5] uses cross-attention on the OpenVLA-OFT backbone, and VLA-ADP [8] further gates tokens by action dynamics; both, however, target compute reduction and leave the token count blind to channel state [14]. Cross-attention has become a standard language-conditioned scoring signal across VLA token-pruning methods; ComVLA differs in that the token budget is set by the channel capacity rather than by a fixed compute target. A. Task Success and Compute Efficiency 

As shown in Table I, existing pruners like LightVLA and VLA-ADP achieve high success rates (97.3% and 95.5%) using content-adaptive token budgets. Their token-importance heads are trained at a fixed budget with no runtime mechanism for adjusting 𝐾 ; ComVLA addresses this by deriving 𝐾 ∗

from the channel SNR at each control step (Eq. (4)). Forcing them below the trained budget drops tokens the importance head can’t rank, reducing to random dropping; Table I’s Random Pruning rows stand in for that regime. The pixel-level codecs stay competitive on success rate but do not reduce cloud compute or token count: they still run full OpenVLA-OFT inference (8.8 TFLOPs) and add codec latency. Random Pruning degrades sharply under tight budgets, falling to 55.7% at 𝐾 ∗=32 and collapsing to 32.6% on the Object suite, a 64.4 pp gap versus ComVLA’s 97.0%. ComVLA reaches 95.4% at 

𝐾 ∗=32 (68 KB/step), reducing transmission by 16 × and cloud compute from 8.8 to 2.3 TFLOPs. Long Horizon’s larger drop ( −4.4 pp at 𝐾 ∗ = 32) tracks its higher baseline difficulty (95.2% vs. 97–98% on the others).

As Table II shows, the robot’s on-device compute drops from 8.80 TFLOPs (running the full OpenVLA-OFT on device) to 0.83 TFLOPs (vision encoder only, ↓ 90 .6%), as the VLM is fully offloaded to the cloud server. INT8 therefore balances bandwidth and accuracy. VI. Conclusion We proposed ComVLA, a framework for bandwidth-adaptive split inference of VLA models. It uses language-guided vision token pruning as a transmission-priority signal, enabling the edge to select task-critical tokens. Transmitting only 32 of 512 tokens, ComVLA reduces per-step TX data by 16 × (1088 KB to 68 KB), cloud compute by 3 .8×, and inference latency by 22%, at a cost of only 1 .5 pp in task success. It remains effective under Rayleigh and Rician fading and tolerates stale CSI feedback up to 200 ms. The semantic structure already inside a VLA suffices for channel-adaptive transmission. Future work targets real-channel evaluation, real-world deployment, and uncertainty-guided token scoring. References
